## TL;DR
Takes JEDI-net's O(N²) all-pairs interaction network (see `1908.05318_jedi_net.md`) and makes it
**O(N) by constraining the edge function to a single affine map and factoring the pairwise sum
into a global-average-pool term** — i.e. it reaches trigger-viable resources specifically by
**removing genuine pairwise interaction**, not by binarizing/quantizing a real pairwise
computation. Trained with HGQ (per-parameter learned bitwidth, mostly <3 bits) and synthesized via
`da4ml` distributed arithmetic, it reaches **0 DSP at up to 128 constituents** on a VU13P, e.g. 64
particles × 16 features: 79 ns latency, 192k LUT, 0 DSP, II=1.

## Summary
JEDI-net's interaction network computes an edge feature `E_ij = f_R(I_i || I_j)` for every ordered
pair of the N constituents via a learned MLP `f_R`, an O(N²) operation in both compute and (for a
naive FPGA implementation) hardware resources — this is confirmed expensive in practice by the
related LL-GNN paper (see below): at 30 particles, a full pairwise interaction network already
consumes 71% of a VU13P/Alveo U250's DSPs. JEDI-linear's fix is architectural, not just a
quantization trick: constrain `f_R` to be **affine** in its two inputs,
`f_R(I_i, I_j) = W_1 I_i + W_2 I_j + C`, then use distributivity to rewrite the sum over all `j`
of `f_R(I_i, I_j)` as `W_2 · (global average pool over j) + W_1 I_i + C` — a single pooled
quantity shared by every `i`, replacing the explicit N×N pairwise tensor entirely. Combined with
HGQ-style per-parameter bitwidth learning and `da4ml`-based distributed arithmetic (constant
matrix-vector multiplies re-expressed as shift-and-add adder graphs, no DSP), the whole network
becomes DSP-free.

## Key methods / contributions
- **O(N) approximation of JEDI-net's O(N²) interaction network** via affine-only edge function +
  global average pooling (their Eq. 4) — trades away heterogeneous, genuinely pairwise edge
  embeddings for "each particle's representation is influenced by the collective behavior of the
  jet" (quoted), which is architecturally closer to Deep Sets than to a true interaction network.
- **HGQ-trained** (per-parameter learned bitwidth; Fig. 7 shows most non-zero weights end up
  below 3 bits) and synthesized through **`da4ml` distributed arithmetic**, giving DSP=0 by
  construction (shift-and-add adder graphs replace multipliers) — same toolchain lineage as our
  own HGQ2/da4ml research (2026-07-04, 2026-07-17 log entries).
- Evaluated at **8, 16, 32, 64, 128 constituents**, with either **3 features** (pT, η, φ) or the
  **full 16 kinematic features** per particle — the 16-feature convention matches ours exactly.
- **No activation×activation interactions in the final design** (WebFetch extraction, accessed
  2026-07-24) — global average pooling is a reduction (sum then a fixed 1/N scale), not a
  pairwise product; all remaining MACs are weight×activation, handled DSP-free by `da4ml`.

## Relevance to BNJetTag
This is the field's own answer to "did anyone slim JEDI-net's interaction network to L1 scale" —
and the answer is a cautionary one for pairwise-feature enthusiasm: **the way to reach DSP=0 at
trigger-relevant constituent counts (up to 128!) was to drop genuine pairwise computation**, not to
binarize/quantize a real O(N²) interaction network. JEDI-linear proves that at trigger scale, an
*approximately*-pairwise (mean-field) architecture, HGQ-trained through the exact `da4ml` toolchain
we are evaluating for ourselves, comfortably clears DSP=0 with strong accuracy (82.4% at 64
particles, 16 features) — but it is NOT evidence for or against whether a genuinely pairwise input
(ΔR/kT/z/m² per actual pair, not linearized away) survives binarization; that combination remains
unpublished (see design-document Q5 in this brief's parent report). Directly actionable for us:
the same `da4ml`/HGQ2 stack this paper uses is the one flagged as a candidate lever in our own
2026-07-17 log entry for the non-folding binary-dense LUT problem — this paper is independent,
published, at-scale evidence that the lever works on a closely related architecture and dataset.
