# Paper library

Annotated notes on the literature behind BNJetTag — 53 papers across six areas.

**→ Start at [`INDEX.md`](INDEX.md).** It lists every paper in one screen with a one-line
reason it matters to us. Find the paper there, then open its note.

Each note has the same shape: metadata (authors, venue, arXiv, code), `## TL;DR`,
`## Summary`, and `## Relevance to BNJetTag`. Every arXiv ID was verified; no benchmark
number was invented — unconfirmed figures are marked "see paper".

PDFs are gitignored. Fetch them with `./download_papers.sh`, which drops each next to its
note. Upstream *code* lives in [`../../reference-code/`](../../reference-code/).
