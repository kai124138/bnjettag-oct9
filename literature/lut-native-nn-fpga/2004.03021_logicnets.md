# LogicNets: Co-Designed Neural Networks and Circuits for Extreme-Throughput Applications

- **Authors:** Yaman Umuroglu*, Yash Akhauri* (*equal contribution), Nicholas J. Fraser, Michaela Blott — Xilinx Research Labs, Dublin, Ireland.
- **Venue / Year:** FPL 2020 (30th Int'l Conf. on Field-Programmable Logic and Applications), Gothenburg, Sweden, Sep 2020.
- **arXiv:** 2004.03021 — https://arxiv.org/abs/2004.03021
- **PDF:** https://arxiv.org/pdf/2004.03021 (full text read directly this session, all 7 pages)
- **Code:** https://github.com/Xilinx/logicnets
- **Topic area:** LUT-native neural networks for FPGAs

## TL;DR
The seed paper of this whole family. Trains sparsely-connected, activation-quantized MLPs whose per-neuron fan-in is deliberately restricted (via sparsity `γ` + activation bitwidth `β`) so that each neuron's entire function (linear + batchnorm + activation) can be exhaustively enumerated into a truth table ("Neuron Equivalent" → "Hardware Building Block"), synthesized as native FPGA LUTs with zero DSPs and no explicit MAC/activation datapath. Evaluated on Jet Substructure Classification (JSC, the Duarte et al. 2018 16-input/5-class hls4ml task) and Network Intrusion Detection (NID, UNSW-NB15).

## (a) Mechanism
A **training methodology**, not a compiler for an arbitrary network: LogicNets *co-designs* topology and circuit together in one three-step flow — (1) define the `X:Y` truth-table granularity (Hardware Building Block/Neuron Equivalent), (2) **train** the whole sparse, quantized DNN from scratch in PyTorch with standard backprop (fixed a-priori random sparsity per Prabhu et al.'s expander-graph technique + learned Brevitas quantization scales), (3) enumerate every trained neuron's `2^X` input combinations into a Verilog ROM/case-statement netlist, then let Vivado's synthesis + heuristic logic minimization map it to LUTs. Quote (§IV-B): *"The second step is followed for each new DNN that needs to be trained and deployed, and takes place in the PyTorch machine learning framework."*

## (b) What it explicitly does NOT do
- **Does not compile a given, externally-trained network.** The network topology (which neurons connect to which, at what bitwidth) must be designed *before* training specifically to respect the fan-in cost model (Eq. 1: `LUTCost(X,Y) = Y/3 · (2^(X-4) − (−1)^X)`), then trained from that constrained topology. There is no path from "here is an arbitrary pretrained dense/binary network" to LogicNets hardware.
- **MLP-only.** No mention anywhere in the text of attention, matmul-between-activations, sequence, or set models — every experiment is a "sparsely-connected, activation-quantized MLP" (§V).
- **Explicit stated limitation (§V-D, verbatim):** *"The first is the inability to map dense networks with high fan-in neurons commonly used in machine learning, instead requiring custom topologies that apply fan-in restrictions via sparsity and activation quantization."*
- Self-imposed fan-in cap for design-space exploration: `X = β·γ ≤ 15` (total input **bits**, not neuron count) for internal layers — though boundary (input/output) layers are given explicit dispensation to exceed it (JSC-L's output layer: `β_o=7, γ_o=5` → X=35; NID-L's input layer: `β_i=2, γ_i=7`). The per-neuron **connection count** (`γ`, the closer analogue of "fan-in" in the everyday sense) is 3–7 across their experiments, never large.

## Cross-cutting notes
- LogicNets is the paper that coined the "no explicit datapath, all operations packed into a truth table" architecture (Fig. 1b) as distinct from LUTNet's "weights baked into LUT equations, but explicit accumulation/activation datapath still present" (Fig. 1a) and from NullaNet (which it credits as introducing "packed into truth table" first, but with a *lossy* don't-care sampling method vs. LogicNets' *lossless* enumeration).
- Cites Duarte et al. 2018 (our own literature/hls4ml-fpga-triggers/1804.06913 brief) directly as its JSC baseline/task source — same task, same paper we already track.

## Verdict
**OCCUPIES** the exact space of "compile a small, fan-in-restricted MLP for the classic 16-feature/5-class JSC task to zero-DSP LUT logic" — this is the founding paper of that solved sub-problem. **ORTHOGONAL** to "compile a given, externally-trained ±1 transformer checkpoint": LogicNets requires training its own bespoke sparse topology from scratch and offers no mechanism to ingest an already-trained, densely-connected, attention-bearing network.
