# N8 / 350k EBOPs / 1000 epochs: single-feature screening

User-authorized 2026-09-12. Seven seed-1 trajectories, one baseline plus six
variants. No seed-2/3 extension is launched before the screening is analyzed.
The older long-budget run continues independently; a fresh baseline is required
because the common epoch loop now provides deterministic ordering and full resume.

| Arm | Only scientific change |
|---|---|
| r0-baseline | None |
| r1-channel | Per-feature activation i/f; shared over particles/batch, per head-feature for attention streams; initial baseline grids broadcast to channels |
| r2-ffn32 | FFN hidden dimension 64 -> 32 |
| r3-prob8 | Attention-probability operand 10 -> 8 bits, integer bits stay 1; internal softmax tables fixed |
| r4-gradual | Training targets: epochs 1–250 1M, 251–500 750k, 501–750 500k, 751–1000 350k; retain PID state |
| r5-recovery | At the first feasible epoch-end at/after epoch800, exclude activation i/f from Adam/weight decay updates; preserve all slots and LR; continue to1000 |
| r6-distill | CE + 0.5 * T^2 KL(teacher || student) + EBOP/width penalties, T=2; frozen seed1 pilot-control teacher, training inputs only |

Common: N8/L1x3, width32,2blocks,4heads, binary absmean weights, no norm, positional
encoding, initial A8 free-width grids, batch256, train496000/validation124000,
Adam beta1 .9/beta2 .98, weight_decay .01, clipvalue1. LR2e-5 with1warmup/999linear
decay. PID init1e-7/p1/i.05/d0/warmup10/logtrue/min1e-10/max1e-3/damping0.
Width regularization1e-8. For channel grids, average the width penalty within
each activation site so adding channels does not increase its total strength. No accuracy stopping and no stop-on-target. TensorFlow
2.21/Keras3.15/HGQ2.1.9, jit_compile=false. Equal-shape kernels/bias/position tables
copied from the reference initialization; changed FFN shapes retain seeded init.

The data split seed is1, independent from the model seed. Within each epoch the
batch order uses SeedSequence([20260912, zero_based_epoch]), identical across arms
and after resume. Mean/std come only from the training split. Shared prepared
arrays are hashed, checked, and used by all runs. Teacher mean/std must match.
The teacher's logits are computed once per attempt, outside the student gradient.

The seven JSON files are generated by configs/gen_ebops_ablation.py. The common
trainer is bnhgq2/ablation.py; run_ablation.py handles data preparation, locking,
teacher fetch and dispatch. Per-channel quantization is an opt-in in qat.py;
existing scalar configs retain their behavior.

## Selection and comparison

All arms admit checkpoints only at <=350000 absolute EBOPs, including early stages
of r4. Rank by validation macro-OvR AUC, then lower EBOPs, then earlier epoch.
If no feasible checkpoint exists, report budget_met=false and deliver the
minimum-EBOP checkpoint as diagnostic. Never attach AUC from a different epoch.
A recovery arm that never becomes feasible after epoch800 reports no freeze.
Record full widths/per-layer cost/PID/LR/objective components, first-feasible epoch,
selected checkpoint, training time and matched initialization hashes. Widths remain
listed as declared trainable variables during recovery, but updates are explicitly
excluded and raw i/f equality is asserted each epoch; recovery_frozen records this.

Classical matrix-multiplication MACs for the fixed shapes (excluding bias, softmax,
normalization, pooling and quantization) are141216 for r0/r1/r3/r4/r5/r6,108448 forr2:
N*F*D + L*(4*N*D^2 + 2*N^2*D + 2*N*D*FFN) + D^2 + 5*D.
The per-channel parameter count includes extra quantizer variables, not neurons.

Single-seed screening does not establish statistical significance. Repeat baseline
and two selected variants at seeds2/3 only in a subsequent authorized stage. Apply
one identical held-out test evaluation protocol after screening decisions are fixed.
A training-subset layer-sensitivity scan is diagnostic, not an eighth training arm.

## GPU scheduling and durability

GPU pool: RTX4090/L40S preferred; L40 allowed. No A10/L4/older GPU fallback and no
H100-only queue. One GPU,4CPU,12Gi RAM per trajectory, three concurrent indexed tasks.
The 2-epoch baseline benchmark uses the actual training data, then the array resumes
R0 from that checkpoint; it does not add epochs or reset state. GPU smoke checks
exercise all variants before the actual baseline benchmark.

No activeDeadlineSeconds on GPU Jobs. Nautilus batch jobs have no universal six-hour
interactive limit; a node failure, eviction, underutilization enforcement or OOM can
still interrupt a job. There is no promise that a pod cannot be killed.

Each epoch writes an atomic checkpoint to the existing kai-data PVC, isolated under
/data/ebops-n8-20260912-ablation/runs/<arm>. It contains the Keras model, Adam state,
PID integral/previous-error/beta, completed epoch, checkpoint-selection state and
recovery state. Keep two complete generations; an incomplete generation cannot
replace the committed pointer. Resume verifies code/config/data hashes and removes
uncommitted history. Per-run file locks prevent concurrent writers. Indexed jobs
allow two retries per arm, using the same persistent state and W&B run identity.
W&B gets a committed backup checkpoint every25epochs and a verified final model
artifact. At most the unfinished epoch should be replayed after a pod interruption,
provided the persistent volume remains available. No training data or credentials
are embedded in the immutable source ConfigMap.

Source/launch files: bnjettag/results/ebops-n8-ablation-20260912/launch/.
Existing shared storage outside this experiment directory is not modified.
